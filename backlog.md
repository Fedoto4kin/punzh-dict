Добавить обработку конструкций:

- `см от X`
- `см. от X`
- `см от: X`
и т.п. уточнить по БД

(возможно нужно добавить для связи поле "тип")

**Требования:**
- выделить X как целевую статью;
- нормализовать X;
- связать через модель «Связи»;
- добавить в админку быстрый поиск по X.

Инвентаризация в HTML уже есть: `audit_see_refs` (корзины `deriv_tagged` /
`deriv_loose`). Связи и тип на `ArticleLink` ещё не заведены.

## 2. Очистить переводы
**Проблема:**
Переводы сейчас избыточны, потому что раньше не было векторного поиска.
Пример: статья *hotkoi* содержит множество однотипных переводов:

- быстрый
- легкий
- легкий на ход
- пользующийся
- пользующийся спросом
- скорый
- спросом
- ход
- ходкий

Особенно замусорены формы глагола **быть** и **становиться**.

**Задача:**
Сделать LLM‑очистку переводов (см скрипт app/agents/build_ontology.py, работаем с Deepseek):

- объединить дублирующиеся значения;
- убрать служебные слова («быть», «становиться»), если они не несут смысл;
- оставить только семантические ядра;
- привести к формату полнотекстового поиска.

**Проблема в поиске:**
Поиск по «быть» не предлагает уточнений → нужно добавить **prio‑фильтр**.

## 3. Поиск неразмеченных помет и помет вне `<i>`
**Задача:**
Найти все случаи:

- помет без `<i>`
- помет внутри текста без тега
- помет с ошибками в орфографии
- помет с латиницей вместо кириллицы

**Решение:**
Скрипт:

- ищет все слова из списка помет;
- проверяет наличие `<i>`;
- предлагает исправление.
