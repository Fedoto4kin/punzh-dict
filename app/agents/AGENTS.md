# Агентная инфраструктура для разработки словаря

## 🎯 Цель

Создать безопасный экспериментальный контур внутри проекта словаря, 
где **архитектор‑агент** формирует планы, а **исполнитель‑агент** пишет код и тесты по этим планам. 
Всё работает локально, изолированно от основной кодовой базы, через Docker-контейнеры.

### 2. Зависимости

**Сборка образа:**
```bash
docker build -f Dockerfile.agent -t agent-tools .
```

### 3. Тестирование подключения к DeepSeek

Скрипт `tools/test_deepseek.py` проверяет:
- наличие переменной `DEEPSEEK_API_KEY`
- соединение с API DeepSeek
- делает простой запрос к модели `deepseek-chat` (или `deepseek-v4-flash`)

**Запуск:**
```bash
docker run --rm -v $(pwd):/app --env-file .env agent-tools /app/tools/test_deepseek.py
```

**Результат (проверен):**
```
✅ Подключение успешно!
📝 Ответ: Привет! Я DeepSeek. Готов к работе!
📊 Статистика: модель deepseek-v4-flash, токенов: 38.
```

---

## 🔐 Переменные окружения

Файл `.env` должен содержать:
```bash
DEEPSEEK_API_KEY=sk-ваш_ключ_сюда
```

Ключ получен на [platform.deepseek.com](https://platform.deepseek.com/), убедится, что баланс пополнен.
