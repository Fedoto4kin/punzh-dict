# План: стоп-токены в многословном русском поиске (вариант A)

Статус: **сделано** (лексический `/search/`, не AI).  
Связь: `docs/backlog-search.md` §P1-stop, `docs/plans/INDEX.md`.

## Проблема

Русский запрос → ILIKE + **токенный OR** (по леммам, P3): статья попадает, если
в `rus_lemmas` есть **хотя бы одна** лемма токена запроса.

На «о корове» / «при …» служебное слово (`о`, `при`) раздувает выдачу.
`STOPWORDS` раньше резал только **ключ сужающего тега**, не seed OR.

## Решение (вариант A)

В многословном запросе (≥2 токена) в token-OR участвуют только **не-стоп**
токены (`tokens_for_token_or`). Однословный «о» / «под» — без изменений.

| Запрос | Поведение |
|--------|-----------|
| `о корове` | только лемма `корова` |
| `под стол` | только `стол` |
| `вон там` | оба токена (не стопы) |
| `о` / `под` | ищем как раньше |
| оба токена — стопы | OR стопов (не пустая выдача) |

`STOP_1C` (корпусный отбор): `без`, `для`, `или`, `под`, `при`.  
`STOPWORDS = STOP_1A ∪ STOP_1B ∪ STOP_1C`.
